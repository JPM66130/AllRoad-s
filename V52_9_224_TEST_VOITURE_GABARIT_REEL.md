# V52.9.224 — Test Voiture gabarit réel

Base stricte : J223.

## But
Isoler l’influence du profil Bus dans une rue étroite et inaccessible aux bus.

## Gabarit Voiture de référence
- longueur : 4,40 m
- largeur : 1,80 m
- hauteur : 1,50 m

## Règle
Aucune correction de caméra, GPS ou routage ajoutée dans ce bloc. On change uniquement le gabarit par défaut du profil Voiture afin de comparer proprement le même secteur avec un véhicule compatible.

## Test WP35
Sélectionner Voiture, préparer le même trajet et comparer la position, le tracé et le cadrage avec le profil Bus.
