# V52.8.4 — Retour à la logique gabarit validée

Cette version repart volontairement de V52.8.2.

La simplification introduite en V52.8.3 est abandonnée : pour les profils à gabarit, le passage par Mes véhicules/Gabarit est conservé. Le premier véhicule peut nécessiter une création/validation ; ensuite, le véhicule enregistré sert de référence et n'est modifié/validé que si nécessaire.

Le Bus reste la référence de comportement.
