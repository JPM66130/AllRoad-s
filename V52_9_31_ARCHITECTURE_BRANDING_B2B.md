# V52.9.31 — Architecture branding B2B

Objectif : préparer la personnalisation commerciale sans créer de versions séparées d’AllRoad’s.

Modes prévus :
- `vehicle` : logo/livrée client sur le véhicule uniquement ;
- `header` : bandeau « AllRoad’s pour [Entreprise] » uniquement ;
- `both` : bandeau + véhicule ;
- `none` : AllRoad’s standard.

Profils compatibles : Voiture, Utilitaire, Camping-car, Bus, Poids lourd.

Règles : une seule base applicative ; branding inactif par défaut ; identité client obligatoire pour activer une personnalisation ; AllRoad’s reste visible ; les fichiers graphiques et droits d’usage devront être validés côté administration avant activation.

Cette version pose le contrat technique uniquement : elle ne modifie pas le rendu WP35 tant qu’aucun client n’est configuré, afin de préserver la base V52.9.30 validée.
