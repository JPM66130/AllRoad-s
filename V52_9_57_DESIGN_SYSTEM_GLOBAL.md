# V52.9.58 — Design System global AllRoad's

Le visuel de navigation validé devient la cible de l'environnement complet AllRoad's.

Règles figées :
- coque standard hors accueil ;
- Carte / Relief / Satellite = même composant, même emplacement sous le header ;
- guidage sous le sélecteur, sans chevauchement ;
- panneaux normaux : rayons, surfaces, ombres et marges cohérents ;
- accueil = signature, dans le même langage graphique ;
- sécurité critique prioritaire sur l'esthétique ;
- portrait/paysage changent la composition, pas la logique.
