# AllRoad’s V52.6.6 — Caméra conduite stabilisée

Cette version cible uniquement la vue de conduite validée sur l’aperçu :

- même caméra pour Démarrer et Démo sans GPS ;
- véhicule générique sans logo dans le tiers inférieur ;
- route orientée vers le haut dans le sens de déplacement ;
- fond cartographique surdimensionné avant rotation pour éliminer les zones vides ;
- recentrage en deux passes après l’ouverture du panneau de conduite ;
- si un calcul se termine après avoir appuyé sur Démarrer, l’application reste en conduite ;
- blocage, retournement et reprise du trajet conservés.
